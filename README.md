# Conectadoa
Sistema de gestão de doações para a ONG Conectadoa.
Projeto Integrador Extensionista · ADS.
## Requisitos
- Git
- Vite+ (comando vp): https://viteplus.dev
## Como rodar
1. Clone o repositório e entre na pasta:
 git clone https://github.com/liwegas-sys/Conectadoa
 
1. Instale as dependências: vp install
1. Copie .env.example para .env
1. Terminal 1, inicie a API: vp run api
1. Terminal 2, inicie o frontend: vp dev
1. Abra http://localhost:5173
